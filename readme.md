# 潜伏之赤途 · 网页版

《潜伏之赤途》是橙光游戏平台（66rpg）上的经典文字冒险游戏（游戏 ID 2992）。本项目将其改造为**可离线运行的纯静态网页版**，并把游戏剧本完整解析为可检索的 JSON / Markdown。

## 在线游玩

**https://chitu.yaozeyuan.online**

也可以本地运行：进入 `site/` 目录双击 `start-server.bat`，浏览器打开 http://127.0.0.1:8321/ 即可。

## 项目说明

- **游戏本体**：`site/` 目录即完整站点。播放器 JS 来自橙光官方 CDN（`c2.cgyouxi.com/website/hfplayer/v2/`），全部 381 个游戏资源（立绘 / BGM / 音效 / 字体）已本地化，通过相对路径加载，无任何外部依赖。
- **剧本数据**：原版播放器读取二进制 `data/game.bin`（ORGDAT 格式）。本项目给 `main.min.js` 打了补丁（见 `resource/_patch_main_js.py`），改为加载 `data/game.json`——这是用橙光官方解析逻辑从 game.bin 无损导出的结构化数据（66 个剧情、8558 条文本事件），方便直接检索游戏文字。
- **可读剧本**：`resource/潜伏之赤途-剧本-可读版.md` 按剧情分话、带分支缩进，像剧本一样从头读到尾；`resource/game.json` 是按语义分类（对话/旁白/选项/跳转等）的清洗版；`resource/game_raw.json` 为无损原始结构。

## 资源来源与致谢

- 游戏原始资源仍在橙光 CDN 上（`dlcdn1.cgyouxi.com/shareres/{md5前2位}/{md5}`），本地资源与线上同源，映射关系见 `resource/原始资源URL映射.csv`。
